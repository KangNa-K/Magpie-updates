Magpie

Privacy Policy

Effective date: October 8, 2026. This policy covers Magpie for Android (package com.agle.app, also known as Agle). Developer and privacy contact: fanghong512@gmail.com.

Storage and library data

Magpie accesses the storage you connect or select, including local files, SMB, WebDAV, Google Drive and OneDrive. It processes asset files, thumbnails, folder names, library metadata, tags and annotations to display and manage your libraries. Library edits are written to the connected storage. The app keeps settings, connection information and cached library data on your device.

Google user data

Google authorization supplies access and refresh tokens. Magpie uses the Google Drive API to locate existing Eagle-format library folders, list files, download assets and metadata, and write library or asset changes you request. It requests https://www.googleapis.com/auth/drive, which permits viewing and managing all Drive files, not only one selected folder. The current library-discovery and editing workflow requires access to existing files; the narrower drive.file permission does not automatically expose those libraries.

Google requests are made from the app to Google. Tokens and storage credentials are stored on the device using encrypted preferences backed by Android Keystore. The developer does not operate a Magpie backend that receives your Drive files or OAuth tokens. Network providers necessarily receive connection information when you use their services.

Optional AI and visual search

When you initiate AI processing, relevant selected asset images and/or text are sent to the model endpoint you configure, using your API key. That endpoint may be a cloud provider or a server you operate. When you initiate Pinterest visual search, the search image is uploaded to Pinterest. These transfers can include assets obtained from a connected cloud library. Review the recipient's privacy and retention practices before using these features; avoid sending confidential data to an endpoint you do not trust.

Magpie does not itself train an AI model on your library content. This statement does not guarantee the data practices of a third-party model endpoint you choose. Magpie has no advertising or user-analytics SDK configured in the current release.

Sharing and use

Magpie uses library data to provide the features you request. It does not sell your library data or use Google user data for advertising. Data is transmitted to your connected storage provider and, when you initiate the optional features described above, the selected processing or search provider. If you contact support, the email and attachments you send are used to handle your request. Do not include credentials in support messages.

Retention and deletion

Source files remain on your selected storage until you delete them there or perform a supported deletion action. Device settings, encrypted credentials and caches may remain until you remove them through the app or clear its Android app data. Clearing app data does not delete source files on remote storage. You can revoke Magpie's Google access in your Google Account's third-party connections settings. Remote providers control retention of data already sent to them; contact them to request deletion where applicable.

Security and your choices

Use trusted storage servers, HTTPS endpoints and device security protections. Credential encryption reduces exposure but no system is completely secure. You may use local libraries without connecting Google Drive and may choose not to use AI or visual search. Review the Google consent screen before granting access.
