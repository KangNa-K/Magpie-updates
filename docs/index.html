Magpie for Android

Magpie is an Android application for browsing and managing Eagle-format asset libraries. It supports local storage, SMB, WebDAV, Google Drive and OneDrive.

Connect your own storage to view assets and edit library information. Optional AI processing uses a model service you configure; optional visual search sends a selected image to Pinterest.

Download signed Android releases

Google Drive access

Magpie requests Google Drive file access to discover existing library folders, read assets and metadata, and save changes you request. The Google consent screen describes the full account-wide permission; it is not limited by Google to a single library folder.
