Magpie

Magpie is an Android application for browsing and managing Eagle-format image and media asset libraries. It lets you organize assets, folders, tags, ratings, annotations and metadata in libraries stored on your device or in storage services that you choose.

Magpie supports local storage, SMB, WebDAV, Google Drive and OneDrive. You can use the app without creating a Magpie account or signing in to this website.

Google Drive access

When you add a Google Drive library, Magpie asks Google for permission to access Drive files. It uses that access to find existing Eagle-format library folders, list and read assets and metadata, and write library changes that you request. Magpie does not upload Drive data to a Magpie-operated server.

Optional features

AI processing and visual search are optional and user initiated. AI requests go to the model service that you configure. Visual search sends the selected image to the search provider shown in the app. Magpie is not an AI image-generation service and does not use Google APIs for AI-generated non-consensual intimate imagery.
